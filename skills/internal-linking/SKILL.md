# Internal Linking Skill

## Overview
This skill governs internal link distribution across the Achaia Labs website to circulate PageRank, guide user discovery, establish semantic topic relationships, and prevent orphaned pages.

## Core Rules
1. **Contextual Service Links:** Every blog post must link naturally to its primary corresponding service page:
   - CRM & business workflows -> `/services/erp`
   - Shopify development & API -> `/services/shopify`
   - Custom software & web development -> `/services/apps`
   - Workflow automation & AI -> `/services/ai-automation`
2. **Case Study Proof Links:** Reference actual portfolio deliverables (`/work/moms-and-moon`, `/work/skmt-trust`, `/work/gaurav-synthetics`, etc.) as tangible evidence within the article copy.
3. **Pillar Cross-Linking:** Related blog articles must link to each other using descriptive, conversational anchor text.
4. **No Naked or Keyword-Stuffed Anchors:** Never use generic "click here" anchors or spam exact-match keyword repetitions. Anchor text must describe the target page accurately.
