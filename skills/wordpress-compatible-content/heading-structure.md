# Heading Structure Standards

## 1. Hierarchy Rules
- **H1:** The single article title. Exactly one per article. Placed above the introduction.
- **H2:** Main topic sections. Each H2 should represent a distinct sub-theme, framework, or operational stage.
- **H3:** Granular subsections, steps, or feature breakdowns under an H2.
- **Heading Order:** Never jump levels (e.g. H1 -> H3 or H2 -> H4).

## 2. Heading Copywriting
- Headings must clearly signal the technical or business value of the section.
- Avoid vague labels like "Overview", "Details", "More Info".
- Use descriptive headings such as:
  - "Why Standard Commercial CRMs Fail High-Volume Real Estate Teams"
  - "Core Architectural Components of a Custom Recruitment CRM"
  - "Shopify Admin API vs. Storefront API: Choosing the Right Protocol"
