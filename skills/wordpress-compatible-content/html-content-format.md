# HTML Content Formatting Standards

## 1. Clean Markup Rules
- **Paragraphs (`<p>`):** Self-contained thoughts consisting of 2 to 4 sentences.
- **Lists (`<ul>` / `<ol>`):** Use unordered lists for feature sets and unordered attributes; use ordered lists for sequential workflows.
- **Tables (`<table>`):** Must include `<thead>`, `<tbody>`, `<th>`, and `<td>` with clear column headers.
- **Blockquotes (`<blockquote>`):** Used for highlighting foundational principles, regulatory notes, or key takeaways.
- **Code Snippets (`<code>` / `<pre>`):** Inline code for variables, endpoints, and file names; fenced code blocks for multi-line JSON or API payloads.

## 2. Portability Verification
Content structured with these standards can be stored directly in JSON, markdown, or relational database text columns without requiring proprietary front-end parser plugins.
