# SEO Strategy Skill

## Overview
This skill governs keyword discovery, search intent analysis, topical clustering, and entity mapping for B2B engineering and digital agency websites.

## Core Rules
1. **Target Real Search Intent:** Every piece of content must map directly to one of three primary intents:
   - *Informational:* User is researching how something works or solving a specific technical/operational problem.
   - *Commercial Investigation:* User is comparing approaches, evaluating vendor types, or looking for partners and agencies.
   - *Transactional:* User is looking to hire, request a quote, or purchase a solution immediately.
2. **Topical Authority Over Isolated Content:** Establish topical authority through cohesive clusters around core capabilities (Shopify Engineering, Custom ERP/CRM, AI Automation, Web Development).
3. **No Keyword Cannibalization:** Every target keyword gets one canonical destination URL. Never target the same primary keyword on multiple blog pages or dilute ranking signals.
4. **Natural Entity Density:** Integrate semantic concepts, related terminology, and entity associations naturally rather than forcing repeated keyword phrases.
