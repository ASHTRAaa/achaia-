# Search Intent Analysis & Mapping

## 1. Intent Classifications

### Commercial Investigation
- **Query Examples:** "CRM for real estate agents", "best CRM for marketing agency", "Shopify developer partner", "AI automation agency", "website developer for small business", "CRM agency"
- **User Mindset:** Evaluating partners, comparing approaches, assessing build-vs-buy tradeoffs, researching vendor criteria.
- **Content Requirement:** Clear frameworks, practical pros and cons, feature comparison checklists, pricing/complexity considerations, and clear signs of technical competence.

### Informational / Problem-Solving
- **Query Examples:** "website building for small business", "CRM in recruitment", "Shopify API developer"
- **User Mindset:** Understanding process steps, technical mechanics, workflows, differences between software categories.
- **Content Requirement:** Comprehensive step-by-step guides, workflow architecture breakdowns, technical diagrams/tables, and actionable advice that delivers value before pitching.

## 2. Intent Satisfaction Framework
Every article must satisfy both explicit and implicit intent:
1. **Explicit Intent:** Direct answer to the search query within the first 2-3 sections.
2. **Implicit Intent:** Underlying operational questions the user needs answered next (e.g. implementation timelines, integration headaches, data migration pitfalls, security, ongoing maintenance).
