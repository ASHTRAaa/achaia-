# Conversion Optimization Skill

## Overview
This skill defines how to integrate friction-free lead-capture opportunities into high-intent blog articles while maintaining editorial dignity and user trust.

## Core Rules
1. **Contextual In-Article CTAs:** Embed call-to-actions that directly address the specific dilemma discussed in the article (e.g. custom CRM architecture, Shopify API integration, business automation).
2. **Reuse Existing Lead Form Backend:** Exclusively utilize the proven SendMyForm API (`https://www.sendmyform.live/api/f/contact-us`). Never introduce rogue forms, unverified backends, or third-party iframe embeds.
3. **Transparent Lead Routing:** Automatically pass contextual metadata (`service`, `source: "blog"`, and article topic) in the payload so the engineering team knows exactly what prompted the inquiry.
4. **Non-Aggressive Experience:** Never deploy disruptive screen-blocking popups, manipulative countdown timers, or intrusive overlay banners.
