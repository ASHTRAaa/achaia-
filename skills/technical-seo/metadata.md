# Technical Metadata Standards

## 1. Title Link Standards
- **Format:** `[Primary Keyword Angle] | Achaia Labs` or `[Primary Keyword]: [Descriptive Angle] | Achaia Labs`
- **Length:** 50 to 65 characters preferred to minimize pixel truncation on Google SERPs.
- **Rule:** Uniquely identify the core thesis of the page. Never duplicate titles across pages.

## 2. Meta Descriptions
- **Length:** 140 to 160 characters.
- **Content:** Compelling summary summarizing the direct takeaway, target audience, and engineering solution.
- **Call-to-Action:** Include a natural, benefit-oriented prompt (e.g., "Explore implementation blueprints, key features, and architecture trade-offs.").

## 3. Open Graph & Social Cards
- `og:type`: `"article"` for blog posts, `"website"` for the hub page.
- `og:title`: Mirrors the primary SEO title.
- `og:description`: Mirrors the meta description.
- `og:url`: Absolute canonical URL (`https://www.achaialabs.tech/blog/[slug]`).
- `og:image`: High-resolution poster (`https://www.achaialabs.tech/work-assets/achaia_showcase_poster.png` or dedicated graphic).
- `twitter:card`: `"summary_large_image"`.
- `twitter:site`: `"@achaialabs"`.
